# React + Vite + tailwindcss

A fully responsive Landing Page built with React.js and Tailwind.css. All in a smooth single-page experience.

🚀 Features

✅ HomePage - Simple & Beautiful hero section.
✅ About - Describes the Team Members. 
✅ Services - Describes the Services Provided by the Organization.
✅ Portfolio - Portfolio of our Designs.

🛠 Tech Stack

Frontend: React.js, React Router.
Styling: Tailwind.CSS classes.
Routing: React Router DOM.
